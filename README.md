# 64 个像素特征能认出哪些手写数字？

本项目研究手写数字 0–9 的分类问题。给定一张 8×8 图像，比较 K 近邻（KNN）和径向基核支持向量机（RBF-SVM）在同一批数字上的识别表现，并用混淆矩阵和错分图像检查两种模型各自遇到的困难。

## 数据来源与评估范围

E. Alpaydin 与 C. Kaynak 于 1998 年公开了 *Optical Recognition of Handwritten Digits*。研究者将归一化的 32×32 二值手写图像划为 64 个互不重叠的 4×4 区块，统计各块的前景像素数。因此，8×8 图像中的每个值都是 0 至 16 的整数。数据采用 CC BY 4.0 许可。[UCI 数据集与原始文件](https://doi.org/10.24432/C50P49) · [许可条款](https://creativecommons.org/licenses/by/4.0/)

UCI 原始划分涉及 43 位书写者，其中 30 人提供训练数据，另 13 人提供测试数据。本项目使用 scikit-learn 随包提供的 `load_digits()`，收录的是这 13 人的 1,797 幅图像。安装依赖后即可离线读取。该接口提供数字标签和图像特征，缺少书写者编号。本项目在这批图像内部按类别分层划分训练集与测试集，同一个人的作品可能出现在两端。报告中的分数适用于这一样本级划分，对新书写者的识别能力需要独立评估。[scikit-learn 数据说明](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html)

## 复现实验

实测环境为 Windows 11、Python 3.14.6。在项目目录中使用以下命令。第一行安装本次实验的包版本，第二行训练与评估，第三行读取结果并作图。

```sh
python -m pip install numpy==2.4.6 scipy==1.18.0 scikit-learn==1.9.0 matplotlib==3.11.0
python experiment.py
python figures.py
```

固定随机种子为 42。训练集含 1,437 张图像，测试集含 360 张图像。训练阶段使用相同的分层五折，按宏平均 F1 选择超参数，在全部训练样本上重训后，对保留的测试样本逐张预测。

| 方法 | 训练阶段选出的参数或策略 | 测试正确数 | 测试准确率 | 测试宏平均 F1 |
| --- | --- | ---: | ---: | ---: |
| 多数类基线 | 恒预测数字 1 | 36 / 360 | 10.00% | 0.0182 |
| KNN | 5 个邻居，等权投票 | 354 / 360 | 98.33% | 0.9830 |
| RBF-SVM | C = 10，γ = 0.1 | 358 / 360 | 99.44% | 0.9944 |

## 结果文件

在 `results/` 中可以核对以下内容。训练集清单和测试预测表中的 `index` 均为 `load_digits()` 数组的原始下标，从 0 起算。

| 文件 | 用途 |
| --- | --- |
| `training.csv` | 对照训练集样本下标及真实标签 |
| `predictions.csv` | 对照每个测试样本的标签与模型预测 |
| `neighbors.csv` | 核对 KNN 错分的 6 张测试图像，每张按欧氏距离从近到远列出 5 个训练邻居的原始下标、标签和距离 |
| `tuning.csv` | 查看各组超参数的交叉验证表现 |
| `summary.json` | 复核数据概况和模型评估指标 |
| `digit_profiles.png` | 查看训练集中每类数字的数量与平均字形 |
| `confusion.png` | 检查 RBF-SVM 对各数字的预测去向 |
| `error_examples.png` | 查看 RBF-SVM 错分样本的图像、真值和两种模型的预测 |

`experiment.py` 是数据检查、模型训练与评估的入口。`figures.py` 生成报告中的图。制图程序优先选择本机可用的中文字体，缺少中文字体时使用英文标注。
